            <h2>README: Class va ID Selektorlarining Farqi va Ishlatilish Maqsadi</h2>
            <p><strong>Nima uchun <code>class</code> (sinf) kerak?</strong></p>
            <p><code>class</code> atributi bir xil dizayn yoki xususiyatga ega bo'lgan bir nechta HTML elementlarini guruhlash uchun ishlatiladi. Masalan, ushbu sahifadagi <code>.card</code> klassi 6 ta turli elementga bir xil shakl, soya va asosiy tuzilmani berish uchun qo'llanilgan. Klasslarni istalgancha ko'p elementlarga takroran yozish mumkin.</p>
            
            <p><strong>Qachon <code>id</code> kerak?</strong></p>
            <p><code>id</code> atributi esa sahifadagi faqat bitta yagona (unikalligi kafolatlangan) elementni belgilash uchun ishlatiladi. Masalan, <code>#header</code> sahifaning bosh qismi va <code>#cta</code> esa asosiy harakat tugmasi uchun faqat bir martadan qo'llanilgan. ID lar JavaScript bilan ishlashda yoki sahifa ichidagi maxsus havolalarda (anchor links) unikal identifikator vazifasini bajaradi.</p>
